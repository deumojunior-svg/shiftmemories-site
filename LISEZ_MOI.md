# ShiftMemories – site (v2)

- `index.html` : site de présentation (FR/EN/DE/IT/ES), histoire, téléchargements.
- `css/`, `js/` : styles, textes traduits (`js/i18n.js`) et bouton APK automatique.
- `app/` : version en ligne (PWA) pour iPhone ET ordinateur – une seule application qui s'adapte à l'écran.
- `assets/`, `icons/` : captures et icônes.
- `politique-confidentialite.html` : à compléter avec vos coordonnées.

## Mettre à jour l'APK
Créer une Release GitHub (ex. v1.0.1), publiée (pas brouillon, pas pré-version), avec le fichier nommé EXACTEMENT
`ShiftMemories-android.apk`. Le bouton du site pointe alors tout seul vers la dernière version.

## Modifier les textes
Les textes sont dans `js/i18n.js` (et le français de départ dans `index.html`).
